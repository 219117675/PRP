## Add to your existing GitHub Pages site without replacing it

1. Open the repository that publishes `https://219117675.github.io/hakizaChris/`.
2. Copy the contents of this folder into a new folder named `prp370/` in the repository.
3. Keep your existing website files. Do **not** replace your current `index.html`, homepage, CSS, or CV files.
4. If your site uses Jekyll, the Markdown pages have front matter and permalinks. If it uses a custom HTML layout, add links to the pages from your existing navigation and adapt the Markdown rendering as needed.
5. Add a link to `/prp370/` from your current homepage or portfolio menu.
6. Commit and push the files, then open the published page and check the navigation.
